Privacy Policy

TAIFEX Night Flow Collector is a personal, noncommercial data-collection project operated by the repository owner. This policy describes its Google Drive connection and research-data handling.

Information accessed

The automation requests Google Drive access through OAuth 2.0 to read existing research outputs, upload validated reports and observation records, and update file indexes. The requested Google Drive scope is broad and may technically allow access beyond the designated research folder. The intended automated operations are restricted by configuration to the project's designated Google Drive folder.

Use and storage

Public TAIFEX reports and locally generated timestamps, validation logs, snapshots and indexes are stored in the project owner's Google Drive. OAuth credentials are stored in GitHub Actions encrypted repository secrets and are used by the automated workflow to obtain authorized access. The repository's public source code must not contain these credentials.

Sharing and retention

This project does not sell Google user data or use it for advertising. Authorized Google Drive data is used for the owner's research automation and is not intentionally shared with third parties through the application. Research output is retained in the owner's Drive until manually removed; Google OAuth access can be revoked from the owner's Google Account settings. Google, GitHub and other infrastructure providers process data as necessary to provide their respective services.

Security and limitations

Use of OAuth credentials and access tokens carries security risk. Access permissions should be limited, secrets rotated as needed, and OAuth authorization revoked if no longer required. As a personal research tool, the application is not offered as a public multiuser service.

Contact

Questions or removal requests concerning this project may be sent through the GitHub repository issue tracker. For Google Account access revocation, use Google Account connections.

Effective date: October 18, 2026
